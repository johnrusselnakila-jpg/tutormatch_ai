# TutorMatch A.I.

A Tutor-Student Matching and Recommender System built with a
K-Nearest Neighbors (KNN) recommendation engine.

## Current Stack

- **Now:** Flutter Web / Dart (this Flutter Web project)
- **Planned:** REST API with FastAPI, backed by PostgreSQL

No backend code is implemented in this repository yet.

## Run Instructions

1. `flutter pub get`
2. `flutter run -d chrome`
